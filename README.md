# 호칭박스

기사 전문에서 지정발언자의 **호칭별 기간**을 찾는 Streamlit 화면입니다. 입력자료(발언문단/발언문장)를 만들 때 기사 날짜에 맞지 않는 호칭을 쓰지 않도록 돕습니다.

## 파일
- `app.py` 화면
- `hobox_core.py` 분석 로직 (화면 없이도 `analyze()`로 호출 가능)
- `default_titles.csv` 기본 예시 호칭 리스트 (화면에서 고쳐 쓸 수 있음)
- `requirements.txt` streamlit, pandas, openpyxl

## 실행
- 로컬: `pip install -r requirements.txt` → `streamlit run app.py`
- 배포: 매직박스와 같은 방법(Streamlit Cloud 등). 별도의 앱으로 올리면 됩니다. API 키 불필요.

## 사용 순서
1. 기사 전문 파일(csv/xlsx, 여러 개 가능)과 성명 입력 → 분석 시작
2. 1단계: 예시 호칭의 시작일·종료일 (현직과 '전(前)'은 따로)
3. 2단계: 예시에 없는 호칭 후보에 체크 → 선택한 호칭 반영하여 다시 계산
4. 엑셀로 내려받기

## 근거 규칙
- [이름+호칭] 뒤가 주격·보조사(은/는/이/가/도)이거나 바로 큰따옴표이고, 같은 문장에 큰따옴표 인용이 있어야 함
- 인용문 안(큰따옴표 홀짝, 작은따옴표 구간)의 이름+호칭은 제외
- '당시 ○○' 형태 제외
- 같은 호칭의 다른 날짜와 60일(전 호칭은 180일) 넘게 떨어진 외톨이 1건은 별도 시트로 배제
- 기사 제목·소제목은 근거로 쓰지 않음
